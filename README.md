# Cancionero Peniel — link viejo

Este repositorio sólo existe para que el link viejo de la app,
`https://jnichiporuk-cmd.github.io/cancionero-peniel/`, siga funcionando:
salta al sitio oficial, **https://cancionero-peniel.firebaseapp.com/**,
conservando lo que traiga el link (invitaciones, canciones compartidas).

No tiene el código de la app. El código vive en un repositorio privado y
estos archivos se publican desde ahí con `publicar_link_viejo.ps1`: no se
editan acá.
